# Hangman Game

A simple console-based Hangman game built with Python as part of my CodeAlpha Python Programming Internship.

## About the Project

This project is a text-based Hangman game where the computer randomly selects a word from a predefined list.

The player guesses the word one letter at a time and gets a maximum of 6 wrong guesses.

## Features

- Random word selection
- Letter-by-letter guessing
- Correct letters are revealed
- Wrong guesses are counted
- Maximum 6 wrong guesses
- Win and lose conditions
- Console-based gameplay

## Concepts Used

- Python Lists
- Strings
- Random module
- While loop
- For loop
- If conditions
- `enumerate()`
- User input
- `break`
